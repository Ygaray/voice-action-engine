correction to the earlier executor analysis in binary-diff.txt ("11 real public-constructor removals"): these are NOT public Kotlin
constructors. Each is declared `internal constructor(` in source (and was at v1.0.1), and TierPolicy is built only through its Builder.
Kotlin compiles an internal constructor to a public JVM <init>, which is why the javap-based helper listed it as public; the Kotlin
metadata marks it internal, so no Kotlin source outside the module can call it, and Metalava (which reads Kotlin visibility) rightly
omits it from core/api.txt.
