### Rules for the answer block

- `packet_status` is one of: pending (nothing answered); partial (some rows answered, none needs-fix, others still pending; answers may arrive in more than one relay, pre-freeze rows first); accepted (every row answered with waive, accept, carry-to-gate-2 or ok, and every category C row with ok, accept or waive); rejected (any row answered needs-fix).
- The cut (release gate waiver) waits for `packet_status: accepted`. The Phase 20 API dumps wait for every category C row to be answered ok, accept or waive.
- A needs-fix on a category C row changes the public API: it voids the dumps committed in plan 20-02 and the wiring pass, and restarts Phase 20 from plan 20-02 (new dump, docs gate, a new wiring SHA and isolated rerun). carry-to-gate-2 is not a valid answer for a category C row, because the API freezes before Gate-2.
- A needs-fix on any other row stops the phase for the orchestrator.
