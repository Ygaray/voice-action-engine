## Execution notes

- Host rules (memory `vae-release-cut-host-oom`): `free -h` and `/proc/meminfo` first and between steps (stop and report
  below 5 GiB MemAvailable); if swap is full the relay asks the operator for the swap reset (agents never run sudo);
  the low-memory GRADLE_OPTS recipe for every run; one Gradle process at a time; each script's real exit status, never
  behind a pipe; an earlyoom kill is re-run ONCE, then reported.
- Network is used by the empty-cache consumer resolution, the :stt artifact and the live probe. No device, no keys, no
  spend.
- On green, keep the dry run's maven-local (KEEP_WORK=1) after this plan: plan 14's prepare-local and the agent's
  verify build use it, and plan 14 removes it.
- Close-on-red rule (any step of Tasks 2-3): record the FAIL line verbatim, write `heavy_gates: red`, set
  `grant: consumed` with a `closed:` (UTC) line and the gate verdict red, remove every kept temp directory, route the
  failure to a gap plan, and the master sends "quiet done". Plan 14 then does not start (its precondition needs
  `heavy_gates: green`); no agent runs on a SHA that must change. A deferred grant writes no `heavy_gates` line.
