## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> engine | On-device model text is untrusted input to SingleShot and the app's resolver |
| native runtime -> app process | A JNI fault kills the process; it must surface as a measured row, not a hang |
