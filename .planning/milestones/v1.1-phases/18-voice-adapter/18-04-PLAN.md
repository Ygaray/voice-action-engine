## Execution notes

- Bash only, no Gradle run. Model the script on `scripts/verify-module-manifest.sh`: a `gate <root>` function that prints
  every violation as `STT CONFINEMENT FAIL: <check>: <item>: <detail>` and returns 1, a `selftest` function that builds a
  pristine copy and plants one violation per case, and a `--root <dir>` option.
- Run after plans 01 and 02: the gate reads the settings, the catalog, the adapter build file and INTEGRATION.md, which those
  plans write.
- Enumerate files with `find` (not `git ls-files`) so the gate also works on a temporary copy; prune `build`, `.gradle`,
  `.git`, `.planning`, `graphify-out` and `.kotlin` directories. The selftest copy is made from `git ls-files -co
  --exclude-standard` filtered to the files the gate reads (settings, catalog, root and module build files, every `.kt`
  source, INTEGRATION.md), so it also works on staged and untracked files.
- The group literal is `com.github.Ygaray.voice-engine-android`; the repository's own group is
  `com.github.Ygaray.voice-action-engine`. Always match the full group string, never `Ygaray` alone.
