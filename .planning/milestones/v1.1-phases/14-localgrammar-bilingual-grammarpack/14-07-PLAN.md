## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Engine -> app normalize hook | App code runs on user speech inside the matcher |
| Engine -> app resolver / gate / sink | App code decides and receives the write |
| Engine -> policy | The app's policy decides whether the tier may run |
| Engine -> trace/events/toString | Output may reach logs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-28 | Tampering | normalize best-guess or survivor-pack fallback | high | mitigate | null/blank rejects; any candidate rejection rejects the command; agreement compared after normalize |
| T-14-29 | Denial of service | throwing or misbehaving hook | medium | mitigate | guardedPlain containment -> grammar_normalize_error; documented non-blocking contract |
| T-14-30 | Information disclosure | hook exception message, slot text, transcript in trace/events/toString | high | mitigate | Codes only; EngineFault class name never recorded as text; RedactionCanaryTest and GrammarRedactionTest sweeps |
| T-14-31 | Elevation of privilege | terminal intent bypassing the gate | medium | accept | A terminal intent records no action and writes nothing (zero-commit by definition, same as SingleShot's terminal tool); the app decides what navigation does |
| T-14-32 | Tampering | grammar runs where policy forbids | low | accept | NO_PROVIDER uses no provider, so every provider policy permits it by design (GRAM-05); maxTier still applies through TierWalk |
</threat_model>
