## Execution notes

- Execution runs on the phase branch (`gsd/phase-14-localgrammar-bilingual-grammarpack`), serially; the driver
  fast-forwards main. Planning did no branch work.
- Host memory: one Gradle invocation at a time with the host-safe recipe in each `<automated>` command; real exit status;
  never `./gradlew --stop`; if earlyoom kills a run, stop and report to the driver.
- Key contract (shared with plan 14-04's GrammarText, which runs in parallel): every input token is a folded key:
  lowercase, vowel accents folded (`dieciséis` -> `dieciseis`, `veintiún` -> `veintiun`), `ñ` kept, apostrophes removed,
  edge punctuation stripped, interior `.` `,` `/` kept (`1,000`, `2.5`, `1/2`), hyphens between two letters already
  split (`twenty-one` -> `twenty`, `one`), other hyphens kept inside the token (`5-10`, `-5`, `twenty-1`). Tests feed keys
  in this form directly; this plan does not depend on GrammarText.
- detekt runs on `src/test` too (LongMethod 60, ReturnCount 2, CyclomaticComplexMethod 15, NestedBlockDepth 4,
  TooManyFunctions 11 per file in main). Keep golden tables as private top-level or companion `val`s, not inside one
  long function; express branches as `when` expressions and small functions; split a main file by responsibility inside
  `number/` if detekt asks. MagicNumber: prefer table-by-index plus `private const val` names (`TEN`, `HUNDRED`,
  `THOUSAND`; never a name matching `^(DEFAULT_|MIN_|MAX_)|TOKEN|ITERATION|CEILING`). If one justified exclude is
  cleaner, add it under `style: MagicNumber: excludes:` with a one-line "lexicon tables are data" comment, and repeat
  detekt's default test globs in that list (`'**/test/**'`, `'**/androidTest/**'`, `'**/commonTest/**'`,
  `'**/jvmTest/**'`, `'**/androidUnitTest/**'`, `'**/androidInstrumentedTest/**'`, `'**/jsTest/**'`, `'**/iosTest/**'`)
  because a configured list replaces the default one. Never a baseline file.
- All main classes here are `internal`; no enum, no data class, no default constructor argument, no public static
  field (`private const val` only).
