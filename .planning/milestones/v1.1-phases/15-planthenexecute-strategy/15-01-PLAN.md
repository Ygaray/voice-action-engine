## Spec-less edge assumptions (no SPEC.md; the edge probe classified PLAN-01..05 as unresolved)

Each is an explicit planner assumption the checker and verifier can hold the plans to:
- PLAN-01 edge: a plan with N valid steps makes exactly 1 provider call and N gate proposals; a step whose tool the
  snapshot never offered, or that is terminal, never reaches the executor (15-02).
- PLAN-02 edge: only a whole string value matching the reference grammar is bound; `$5.00`, a mid-string reference and
  object keys are never rewritten; an unresolvable reference never guesses a value (15-02).
- PLAN-03 edge: the model is called at most twice per plan tier; a replan happens only while nothing was applied or
  held; the needs-lookup escape spends exactly one call and zero executor/gate calls (15-02, 15-03).
- PLAN-04 edge: every stop after any apply or hold is an Escalate (suppressed by TierWalk) or, for a hold after a
  commit, a terminal partial Completed (RT-01); never a Failed (15-04).
- PLAN-05 edge: onFailed fires only for provider failures other than NoToolCall/Refusal, on either the plan or the
  replan call; never for a refused model, a token ceiling, a gate decision or a throwing executor (15-05).
