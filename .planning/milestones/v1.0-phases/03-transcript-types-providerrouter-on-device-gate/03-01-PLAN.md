<objective>

Widen the Phase 2 sealed allow-list to admit exactly `Message` and `AssistantPart`, in this same plan, so the surface gate never trips at the phase gate.

Purpose: SingleShot is a one-message transcript and AgenticLoop is a multi-turn one; defining the full multi-turn model now means Phases 4, 5, 7, 8 and 9 never redesign it. These shapes are frozen by Metalava at the v1.0.0 cut, so the growth rules (no default arguments, explicit secondary constructors, open vocabularies) are applied from the first line.

Output: 5 main files, 2 test classes, 1 script edit.
</objective>

### Planning decisions recorded here (resolved in-plan, no checkpoint; pre-tag shapes are two-way until v1.0.0)

1. Sealed set (open question 1): `Message` and `AssistantPart` are sealed; every other new vocabulary (`ToolChoice`, `StopReason`, `ModelResult`, `CredentialLookup`, `OnDeviceAvailability`, `CachingMode`) stays open. Rationale: the three message kinds and the two neutral part kinds are the universe by contract (D-01 fixes the parts to Text and ToolCall; a new message kind would need a contract amendment anyway), the two provider mappers switch over them exhaustively, and Phase 2's script header frames the allow-list as "contract-closed" types, which these are. The allow-list edit lands in this plan (Task 1) with its header comment.
2. On-device cause code (open question 2): `ProviderUnavailable(ON_DEVICE, "on_device_unavailable")` on both the pre-check path and the router path (one gate, one code).
3. D-10 known limitation (open question 3): an EXPLICIT_BREAKPOINTS turn with read 0 and write above 0 on turn 2 or later (prefix drift) is not flagged; D-10 is implemented exactly as locked (03-09).
4. Estimator divisor (open question 4): default 4.0 characters per token, app/provider-overridable per model in `ModelCapabilities.charsPerToken`, and the estimate is capped by the response's own `inputUncached + cacheRead + cacheWrite`. This refines CONTEXT's "about 3" hint: 3.01 is the measured A10 tool-JSON ratio, and erring silent needs the larger divisor.
5. `ToolSpec` grows by `strict: Boolean?` only, through `@JvmOverloads` on its primary constructor: its existing (and only) public 5-argument JVM constructor stays, and the 3-, 4- and 6-argument shapes are added (03-05).
6. `UserMessage` is text-only (`UserMessage(text)`): voice commands are text; other content kinds would be additive constructors later.
7. Every new constructor in `transcript/` and `provider/` declares no default argument values (explicit secondary constructors instead); 03-05 adds an ApiShapeTest rule that enforces it mechanically. `ToolSpec` (Phase 2 type) is the single exception, grown with `@JvmOverloads` per orchestrator decision 6.

## Type contract (exact public shapes this plan creates)

All regular final classes unless stated; every public member has KDoc; no copy/componentN-generating modifier; no enum; constants are companion `val`s or top-level `private const val`s (never `public const val`); no constructor declares a default argument value.

- `Message`: `public sealed class Message`. KDoc: the three kinds are the whole universe of a neutral conversation; a mapper switches over them exhaustively.
- `UserMessage(text: String) : Message()`. No validation (constructing input never throws, like `CommandInput`). `toString` = `UserMessage(textLength=<n>)`.
- `AssistantMessage(parts: List<AssistantPart>, nativeReplay: NativeReplay?) : Message()` plus secondary `AssistantMessage(parts: List<AssistantPart>)` (no replay). `parts` is a copy and may be empty (a provider can return an empty turn). Derived `toolCalls: List<AssistantPart.ToolCall>` in order. `nativeFor(provider: ProviderId, model: String): JsonElement?` per D-01. `toString` = `AssistantMessage(parts=<n>, toolCalls=[<tool names>], nativeReplay=<provider>/<model> or none)`.
- `ToolResultsMessage(results: List<ToolResult>) : Message()`: copy; requires at least one result and distinct `callId`s (one batch per turn). `toString` = `ToolResultsMessage(results=<n>, errors=<count of isError>)`.
- `ToolResult(callId: String, content: String, isError: Boolean)` plus secondary `ToolResult(callId: String, content: String)` (isError false). Requires non-blank `callId`. `toString` = `ToolResult(callId=<id>, contentLength=<n>, isError=<b>)`.
- `AssistantPart`: `public sealed class AssistantPart` with nested `Text(text: String)` (`toString` = `Text(length=<n>)`) and `ToolCall(id: String, name: String, arguments: JsonObject)` (requires non-blank id and name; `toString` = `ToolCall(id=<id>, name=<name>, argumentCount=<n>)`). KDoc: thinking and any other provider block lives only in `NativeReplay.raw`.
- `NativeReplay(provider: ProviderId, model: String, raw: JsonElement)`: requires non-blank model. KDoc: the provider's own assistant turn verbatim, possibly holding thinking blocks; stored by reference, never rebuilt, never mutated, never printed. `toString` = `NativeReplay(provider=<p>, model=<m>)`.
- `ToolChoice`: `public abstract class ToolChoice internal constructor()` with nested public `Auto()` and `Required(toolName: String)` (requires non-blank). Equality by class and field. `toString` = `ToolChoice.Auto` / `ToolChoice.Required(toolName=<name>)`. KDoc: open set, keep an `else` branch.
- `CacheDirective(staticPrefix: Boolean, conversationTail: Boolean)` plus secondary `CacheDirective(staticPrefix: Boolean)` (tail false). Equality by both flags; `toString` prints both. KDoc: staticPrefix asks the provider to cache the frozen tools plus system prefix; conversationTail additionally caches the moving tail.
- `ModelRequest(system: String, messages: List<Message>, tools: List<ToolSpec>, toolChoice: ToolChoice, maxTokens: Int, cache: CacheDirective)` plus secondaries `ModelRequest(system, messages, maxTokens)` and `ModelRequest(system, messages, tools, maxTokens)`; both secondaries use `ToolChoice.Auto()` and `CacheDirective(staticPrefix = true)`. Lists copied. Validation with `require` (messages non-empty; maxTokens >= 1; tool names distinct; a `Required` choice names a tool in `tools`). `toString` = `ModelRequest(systemLength=<n>, messages=<n>, tools=[<names>], toolChoice=<..>, maxTokens=<n>, cache=<..>)`. KDoc: no model id (bound per command by the router); maxTokens comes from the command's policy.
- `StopReason`: `@JvmInline public value class StopReason(public val value: String)`, `init` requires `isStableCode(value)` (reuse `failure/ReasonSupport.kt`). Companion `val`s: `END_TURN` end_turn, `TOOL_USE` tool_use, `MAX_TOKENS` max_tokens, `REFUSAL` refusal, `PAUSE_TURN` pause_turn, `CONTEXT_WINDOW_EXCEEDED` context_window_exceeded, `OTHER` other. `toString()` = value. KDoc: open set; providers map unknown wire values to `OTHER` and keep the raw value only inside `NativeReplay`.
- `ModelResponse(message: AssistantMessage, stopReason: StopReason, usage: Usage, requestId: String?)` plus secondary without `requestId`. `toString` = `ModelResponse(parts=<n>, toolCalls=[<names>], stopReason=<v>, usage=<usage>, requestId=<id or null>)`.
