## Code meanings (KDoc one-liners to use)

| Constant | Meaning |
|----------|---------|
| PROVIDER_NOT_SELECTED | the app's selection source answered "not configured" for this tier |
| SELECTION_SOURCE_ERROR | the app's selection source threw |
| PROVIDER_NOT_ALLOWED | the selected provider is not declared by the tier, or the command's policy forbids it |
| PROVIDER_NOT_REGISTERED | no provider is registered in the pipeline for the selected provider id |
| CREDENTIAL_MISSING | the credential source has no key for the selected provider (or no source is set) |
| CREDENTIAL_UNREADABLE | the key exists but cannot be read; the user should re-enter it |
| CREDENTIAL_SOURCE_ERROR | the credential source threw |
| CREDENTIAL_MISMATCH | the credential source returned a key for a different provider; it was not used |
| CAPABILITY_LOOKUP_ERROR | a provider default or app override for the model's capabilities threw |
| CAPABILITY_REFUSED | the request needs a capability the model lacks; nothing was sent |
| PROVIDER_ERROR | the provider threw instead of returning a result |
| PROVIDER_FALLBACK | on-device inference was unavailable, so the selection's declared fallback answered |
| FALLBACK_REFUSED | the declared fallback was forbidden by the policy or the tier's declaration, so nothing was sent |
