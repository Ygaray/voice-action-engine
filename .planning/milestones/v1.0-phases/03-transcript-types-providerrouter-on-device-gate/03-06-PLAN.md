<objective>
Build the router core (PROV-02, the no-fallback half of PROV-10): an internal `ModelRouter` whose `bind(...)` resolves selection -> tier-declaration and policy gate -> on-device probe -> provider registration -> credential for that provider only -> capabilities, refusing with a specific typed reason and a trace code after zero provider calls, and returns a public `BoundModel` whose `complete(request)` checks capabilities, calls the provider through `guarded`, and records the turn. Purpose: this is where "missing key is NotConfigured before any call", "keys never cross providers" and "never a silent climb" become structural. The on-device fallback (03-08) extends ModelRouter.kt and the cache diagnostic (03-09) extends BoundModel.kt, in disjoint halves.

Output: 2 new main files, 1 new test class.

## Resolution contract (the order is part of the behavior)

1. Selection: no source set, or `select(SelectionRequest(tier))` returns null -> refuse `NotConfigured(null)` + `provider_not_selected`. The call is `guarded`: a fault records `selection_source_error` and refuses with `Timeout()` for a leaked timeout, else `Unexpected(errorClass)`.
2. Gate for the selected provider p: p not in the tier's declared providers -> `ProviderUnavailable(p, "provider_not_declared")`; `policy.allowedProviders` excludes p, or `policy.offlineOnly` and p is not ON_DEVICE -> `ProviderUnavailable(p, "policy_forbids_provider")`; both record `provider_not_allowed`. (Implement this gate as one internal function: 03-08 re-applies it to the fallback.)
3. On-device: when p is ON_DEVICE it is usable only if the router's probe function returns true (`guarded`; a fault records `on_device_probe_error` and counts as unavailable) and an ON_DEVICE provider is registered; otherwise refuse `ProviderUnavailable(ProviderId.ON_DEVICE, "on_device_unavailable")` + `on_device_unavailable`, before any credential lookup. (03-08 inserts the declared-fallback branch here.)
4. Registration: no AiProvider registered for p -> `NotConfigured(p)` + `provider_not_registered`.
5. Credential, only when the provider's `requiresCredential` is true, asked for p only: no source or `Missing` -> `NotConfigured(p)` + `credential_missing`; `Unreadable(c)` -> `CredentialUnreadable(p, c)` + `credential_unreadable`; a `guarded` fault -> `CredentialUnreadable(p, "source_error")` + `credential_source_error`; `Present` whose credential's provider is not p -> `NotConfigured(p)` + `credential_mismatch` (never sent); any other leaf -> `NotConfigured(p)` + `credential_missing`.
6. Capabilities: `guarded` `table.lookup(p, model)`; a fault -> `Unexpected(errorClass)` + `capability_lookup_error`.
7. Bound: a routed handle holding the binding privately.

`complete(request)` on a refused handle returns `ModelResult.Failure(refusal)` (no call, no turn, no further code). On a routed handle: a request with tools on `supportsTools == false` -> `Failure(ModelUnsupported())` + `capability_refused`, no call, no turn; otherwise read the clock, call `guarded { provider.complete(ProviderCall(model, request, credential, capabilities)) }` (fault -> `provider_error` and `Failure(Timeout())` for a leaked timeout else `Failure(Unexpected(errorClass))`), read the clock again, record a `TurnRecord(provider, model, stopReason.value or null, tool names of the response's tool calls, usage or Usage.ZERO, latency, binding.fallbackFrom)` through `RunRecorder.turnRecorded(strategy, turn)`, and return the result.
