<objective>
Build the D-01 gated release script and prove its happy path end to end before it guards an immutable tag.

Purpose: tags are immutable (§11 rule 6). JitPack caches a tag's build for good, and a wrong tag can only be superseded by spending a version number. Everything checkable before the tag is checked by one script, the irreversible push is a separate mode, and a sandbox proves the full preflight and cut work. 11-05 then proves every gate goes red when it should.
Output: `scripts/release-cut.sh`, a small backward-compatible option in `scripts/jitpack-dry-run.sh`, and the happy-path evidence.

This plan and 11-05 land before the wiring SHA (11-06), so the script is part of the tested tree. A later fix to it would be a non-.planning change after the wiring SHA, which means another wiring rerun. The happy path therefore runs the full gate set, not a subset.
</objective>
