<objective>
Close Phase 2 security finding O-1 before the agentic loop exists, and move the limit helpers the loop will share with SingleShot out of the single-shot package. A multi-step agentic run is where a mid-batch cancel matters (Runtime Decision O-1), so the coordinator must stop a batch at the next item once the caller is cancelled; and the loop must enforce the same 6 / 60000 / 4096 limits SingleShot does with the same code, not a copy (Runtime Decision limits precondition).

Purpose: LOOP-03 (nothing committed is hidden, and nothing is committed after a cancel) and the shared bounds LOOP-02 reads from `TierPolicy`. D-04: the coordinator owns state; the loop will never catch cancellation, so the coordinator is where cancel-safety lives.
Output: one changed line of coordinator logic plus its regression tests, one new internal helper file, SingleShot re-pointed at it, one evidence file.

Contention: the phase runs strictly sequentially, one plan per wave (wave 1 is this plan only); this plan never runs two Gradle invocations at once.

Mandates covered: 3 (O-1 fixed additively with BatchCancellationTest, disposition recorded); 2 (shared ceiling helpers the loop's limits reuse).
</objective>
