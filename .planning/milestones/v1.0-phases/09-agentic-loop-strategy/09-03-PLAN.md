<objective>
Build the thinnest working agentic loop end to end on the signed-off seam: one command goes from transcript through a tool turn, the gate, the sink and back to the model, then ends on a prose answer. The tier reuses Phase 7's `ToolSpecProvider`/`ToolingSnapshot` (singleShotTool null) and `UserTurnRenderer`, sends `ToolChoice.Auto` with parallel calls allowed, keeps system and tools as the invariant cached prefix, and is bounded by the policy limits from its first commit. Later plans widen the gate path (09-04), the guards and limit tests (09-05) and the exit paths (09-06) on this proven slice.

Purpose: LOOP-01 (an AgenticLoopStrategy over the app's ToolSpecProvider and ToolExecutor, every mutation through the gate), the structural half of LOOP-02, and CLN-02's "no hard-coded tool count" as behavior.
Output: three new internal-or-public `:core` main files in `core.strategy.agentic`, one test support file, two test classes.

Contention: the phase runs strictly sequentially, one plan per wave (wave 3 is this plan only); this plan never runs two Gradle invocations at once.

Mandates covered: 1 (same userTurn seam; SB byte-exact framing at core level; ToolSpecProvider/ToolingSnapshot with singleShotTool null; system+tools invariant prefix), 2 (limits enforced in code from session.policy/session.tokensUsed; tested in 09-05), 5 (ToolChoice.Auto and singleToolCall false on every request), CLN-02 (1, 2 and 25 tools).
Behavior defaults: as relayed in 09-02 Task 3 (Q3/Q4/Q9/Q10). If `evidence/seam-signoff.txt` carries a CARRY for item 2 or 9, this plan was amended before execution (Task 1 precondition).
</objective>
