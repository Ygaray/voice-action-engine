<objective>
Turn every 2xx Chat Completions answer from either vendor into a typed engine result with the agreed precedence (D-10): the 200 error envelope first (D-11), then refusal, length, tool calls by presence (D-09), the no-tool-call case and unknown endings; decode `arguments` strings strictly (bad JSON is `MalformedToolArgs`), never fill defaults (D-08, PROV-12), and normalize usage so cached tokens are not double-counted (TEL-01).

Purpose: success criterion 2 (typed outcomes, never crashes or fabricated parses) and the decode half of success criterion 3 (normalized usage).
Output: two internal chat files, the shared response-fixture file, one test class.

Contention: the phase runs strictly sequentially, one plan per wave (wave 5 is this plan only; it starts after 05-04 has merged), so no two plans ever run `:providers` Gradle tasks at the same time; this plan never runs two Gradle invocations at once, uses task-scoped `:providers` commands until its final `:providers:check`.
</objective>

| provider -> library | 2xx bodies are untrusted JSON, possibly a routed upstream's raw shape |
| library -> app | decoded tool arguments drive app mutations; usage drives the token ceiling |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-16 | Tampering | a fabricated or truncated tool call reaching the app as a mutation | high | mitigate | arguments must parse to a JSON object; length never decodes arguments; blank id/name malformed (Task 2) |
| T-05-17 | Information disclosure | refusal, reasoning or error text copied into parts, failures or exceptions | high | mitigate | refusal never in parts; carrier exception holds a reason only; CANARY tests (Task 3); 05-10 canary through the pipeline |
| T-05-18 | Tampering | a 200 answer that is an error accepted as success | medium | mitigate | envelope check on every 2xx before choices (Task 2) |
| T-05-19 | Denial of service | double-counted cached tokens tripping the token ceiling early, or a negative count throwing in Usage | medium | mitigate | subtraction with clamps and a 0 floor (Task 3); 05-09 parity test |
| T-05-20 | Tampering | hostile native_finish_reason or body id breaking FailureDetails or ModelResponse | low | mitigate | safeToken / safeRequestId (Task 2) |
