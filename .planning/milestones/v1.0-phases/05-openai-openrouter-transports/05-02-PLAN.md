<objective>
Give the Chat Completions dialect its model knowledge: the internal vendor config behind the two future public factories (D-01), the public capability facts per vendor including OpenRouter id normalization (D-02) and the OpenAI-only tools block for GPT-6 Astra / 6.1 Sol (D-04), and the internal wire-parameter rules by model family (D-03). Output: three internal chat files and two test classes.

<assumption_delta_decision>
Primary noun: the internal `ChatVendor` config with two public factories over it (`ChatCompletionsProvider.openAi {}` / `.openRouter {}`, built in 05-06), per D-01.
Decision: no-change. A second vendor is added as a second `ChatVendor` instance (data: base URL, provider id, request-id source, two wire flags), not as a subclass, a strategy interface or a new public type.

</assumption_delta_decision>
