After this plan all five contract-closed sealed types exist, so the surface review switches to `--expect-sealed-complete`.

## Type contract (exact public shapes this plan creates)

Conventions: regular classes (no copy/componentN), explicit visibility, KDoc on every public member, redacted `toString` on anything holding reply, carry, context, reason, content or arguments (print ids, codes, counts, lengths and simple class names only), constants as top-level `private const val`. Growing input classes grow by added constructor overloads, never by adding a defaulted parameter to an existing public constructor (research E1). Internal constructors may use default parameters (not API) to stay under detekt LongParameterList (constructorThreshold 8).

Strategy seam (package `...core.strategy`):
- `CommandStrategy`: `public interface` with `public val id: StrategyId` and `public suspend fun execute(input: CommandInput, session: CommandSession): StrategyOutcome`. KDoc: strategies never write; every write is a `ToolStep` passed to `session.submit`.
- `CommandSession`: `public abstract class CommandSession internal constructor()` with abstract public `runId: String`, `parentRunId: String?`, `strategy: StrategyId`, `policy: TierPolicy`, `carry: Any?`, and `public abstract suspend fun submit(step: ToolStep): DispatchResult`; a final `toString` = `CommandSession(runId=<id>, strategy=<id>, carry=<class|null>)`.
- `StrategyOutcome`: `public sealed class`. Nested: `Completed` primary `(reply: String?, terminalCall: TerminalCall?)` + secondary `(reply: String?)`, init `require(reply == null || terminalCall == null)`; `Escalate` primary `(reason: EscalationReason, carry: Any?)` + secondary `(reason)`; `NoMatch` public no-arg constructor; `Failed` primary `(reason: FailureReason, details: FailureDetails?)` + secondary `(reason)`. All public constructors; redacted toString.

Commit seam (package `...core.commit`):
- `ToolStep`: `public sealed class`. `Finished` primary `(toolName: String, kind: FinishedKind, result: StepResult, context: Any?)` + secondary `(toolName, kind, result)`. `Mutation` primary `(mutations: List<PendingMutation>)` with `require(mutations.isNotEmpty())` and a defensive copy, + secondary `(mutation: PendingMutation)`.
- `PendingMutation`: `public interface` with abstract `toolName: String`, abstract `suspend fun apply(): StepResult`, default-bodied `targetIds: Map<String, String>` (empty) and `context: Any?` (null). KDoc: apply runs only after the gate admits; a deferred commit runs later against possibly-changed state, so apply must re-validate; context is opaque (for example a pre-mutation snapshot).
- `StepResult`: public primary `(contentForModel: String, isError: Boolean, appOutcomeToken: String?, targetIds: Map<String, String>)` + secondaries `(contentForModel)` and `(contentForModel, isError)`. KDoc: appOutcomeToken is the app's verbatim outcome string and reaches the sink byte-identical.
- `DispatchResult`: internal constructor; public `contentForModel: String`, `isError: Boolean`, `held: Boolean`, `actions: List<ExecutedAction>`. KDoc: held means not done and the model must not retry. Content rule: single-mutation step = that mutation's content (held: the held JSON); multi-mutation step = contents joined with a newline in dispatch order (held: the held JSON once).
- `PreApplyGate`: `public fun interface PreApplyGate { public suspend fun admit(proposal: CommitProposal): GateDecision }`. KDoc: only Admit writes; any throw is treated as a hold (fail-closed); suspend mode waits inside admit, defer mode returns Hold.
- `GateDecision`: `public sealed class`. `Admit` primary `(amended: List<PendingMutation>?)` + secondary `()`; `Hold` primary `(reason: Any?, appOutcomeToken: String?)` + secondaries `()` and `(reason: Any?)`. Redacted toString (reason class name, token presence, amended count).
- `CommitProposal`: internal constructor `(runId: String, parentRunId: String?, mutations: List<PendingMutation>)`; public getters; toString `CommitProposal(runId=<id>, mutations=<n>, tools=[<names>])`.
- `CommitSink`: `public interface` with `public suspend fun onAction(event: ActionEvent)` and `public suspend fun onRunClosed(runId: String, termination: RunTermination)`. KDoc: per action as it happens, in order, awaited; onRunClosed exactly once per run on every exit path including cancellation; a throw is caught and recorded, never causes a re-apply.
- `ActionEvent`: internal constructor `(runId: String, parentRunId: String?, action: ExecutedAction)`.
- `ExecutedAction`: internal constructor `(position: Int, kind: ActionKind, applied: Boolean, appOutcomeToken: String?, toolName: String, targetIds: Map<String, String>, context: Any?, mutating: Boolean = true)`; public getters. KDoc: position is the identity (engine-assigned, monotonic within a run in dispatch order), never a provider tool-use id; applied is true when the app's apply ran (committed and errored applies), false for held, preview and rejected. toString redacted.
- `HeldProposal`: internal constructor `(runId: String, parentRunId: String?, mutations: List<PendingMutation>, reason: Any?, appOutcomeToken: String?)`; public getters; KDoc: in-memory only. toString `HeldProposal(runId=<id>, mutations=<n>, reason=<class|null>)`.
- `RunTermination`: `public sealed class` with `internal abstract val effects: RunEffects` and public getters `runId`, `parentRunId`, `executed`, `commits` (kind committed, in order), `held`, `trace`, plus `public abstract val code: String`. Leaves with internal constructors: `Done(effects, partial: Boolean)` code done; `Failed(effects, reason: FailureReason, details: FailureDetails?)` code failed; `Exhausted(effects, lastReason: EscalationReason?)` code exhausted; `Cancelled(effects)` code cancelled. Four leaves cover the five A17 exit paths (budget exceeded and provider error are distinct `Failed` reasons).

Pipeline (package `...core.pipeline`):
- `CommandOutcome`: `public sealed class` with `internal abstract val effects: RunEffects` and public getters `runId`, `parentRunId`, `executed`, `commits`, `held`, `trace`. Leaves with internal constructors: `Completed(effects, reply: String?, terminalCall: TerminalCall?, partial: Boolean)` (no default on any of its parameters, so no DefaultConstructorMarker constructor exists; plan 06 asserts this by reflection), `Failed(effects, reason: FailureReason, details: FailureDetails?)`, `Unhandled(effects, lastReason: EscalationReason?)`. KDoc: offer Retry only when `commits` is empty. Redacted toString. `internal class RunEffects(runId, parentRunId, executed, held, trace)` lives in this file; `commits` is derived from executed by kind committed.
- `CommandPipeline`: `public class CommandPipeline internal constructor(...)`; `public val tiers: List<StrategyId>`; `public suspend fun execute(input: CommandInput): CommandOutcome`; toString `CommandPipeline(tiers=[...])`.
- `PipelineDsl`: `@DslMarker public annotation class PipelineDsl`.
- `PipelineBuilder`: `@PipelineDsl public class PipelineBuilder internal constructor()` with `public fun tier(strategy: CommandStrategy)`, `public var gate: PreApplyGate? = null`, `public var commitSink: CommitSink? = null`, `public var policy: TierPolicySource` (default `TierPolicySource.fixed(TierPolicy.DEFAULT)`), `public var clock: () -> Long` (default: monotonic milliseconds from `System.nanoTime()`), `public var runIds: () -> String` (default: `java.util.UUID.randomUUID().toString()`), and internal `build()`.
- `commandPipeline`: `public fun commandPipeline(block: PipelineBuilder.() -> Unit): CommandPipeline`, top level in PipelineBuilder.kt (its JVM facade class name is API; never move it).

Telemetry (package `...core.telemetry`):
- `CommandTrace`: internal constructor; public `runId`, `parentRunId`, `language: String?`, `transcriptLength: Int`, `attempts: List<TierAttempt>`, `codes: List<TraceCode>`, `startedAtMillis: Long`, `durationMillis: Long`. Plan 08 adds `usage`.
- `TierAttempt`: internal constructor; public `strategy: StrategyId`, `outcome: String` (completed, escalated, no_match, failed, escalation_suppressed), `escalationReason: EscalationReason?`, `suppressedEscalation: EscalationReason?`, `failure: FailureReason?`, `latencyMillis: Long`. Plan 08 adds turns, provider, model, usage.
