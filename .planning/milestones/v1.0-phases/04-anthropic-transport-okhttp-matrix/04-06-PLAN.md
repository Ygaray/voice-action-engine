<objective>
Make "the app requires this tool" work on every Anthropic model: forced tool choice where the model accepts it, the auto + strict + instruction reshape where the verified table (or the app) says it does not, a single reactive reshape on the specific forced-tool 400 for ids the table does not know, and a typed `NoToolCall` when the model still answers without the tool (PROV-07, D-06, D-07). Prove the Anthropic leg of PROV-12: strict only when there are no optional properties, and an omitted optional arrives absent.

Purpose: Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 return 400 on every forced request; SingleShot (Phase 7) depends on forced-or-equivalent tool calls and maps NoToolCall to Escalate.
Output: reshape encoding, strict predicate, reactive matcher in the shared budget, NoToolCall decoding, two test classes.
</objective>
