<objective>
Make a multi-turn transcript that cannot be replayed honestly fail loudly, typed, and before any HTTP request, on every shipped transport. Today both mappers quietly rebuild a turn stamped for another provider or model (XCR-02, D-03), and nothing checks that every tool call is answered (D-04). This plan adds one pure pre-flight check that both transports run once per logical call (the phase tracer, proven end to end through the routed pipeline), and it hardens both encoders so a stamped turn is never rebuilt.

Two tests are reversed on purpose because Phase 8 supersedes the behaviour they pinned: `AnthropicEncoderTest.aMatchingNativeReplayIsSentVerbatimAndAnyOtherIsRebuiltFromParts` and `ChatMessageEncoderTest.aReplayFromAnotherVendorProviderOrModelIsRebuilt`. The rest of those classes stays as it is.

Purpose: Phase 9's loop replays whole histories, so a silent rebuild would break thinking signatures and the cache, and a dangling call would become an opaque provider 400.
Output: one new internal main file, two transport edits, two encoder edits, one :core KDoc rewording, one new test class and four extended test classes.

Contention: the phase runs strictly sequentially, one plan per wave (wave 1 is this plan only). Every plan edits `:providers`, so this plan never runs two Gradle invocations at once.
</objective>

## Plan-level decisions (Review Dispositions)

- **Research A9, kind-only failure codes:** confirmed as a deliberate deviation from the decision-map option wording "naming the missing id". The locked D-04 text says "enforce in the mapper". It does not require the id in the reason. `FailureReason.Other.code` must be a short safe token, and ids are model-controlled text that the secrets rule keeps out of reasons, `toString` and traces. The strategy holds the transcript, so the id can be recovered from it. This is not a contract conflict, so no human decision is needed.
- **Encoder backstop:** a mismatched stamp that reaches an encoder directly (a test, or a future internal caller) throws `IllegalStateException` with a fixed message. It never rebuilds silently. A transport cannot reach that path, because its pre-flight refuses the turn first.
