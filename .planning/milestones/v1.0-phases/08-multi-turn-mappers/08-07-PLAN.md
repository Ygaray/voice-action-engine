<objective>
Prove SC4 on every dialect and every golden: each dialect keeps its own cache directive, and the cached prefix bytes stay identical on every iteration of a multi-turn conversation (D-10).

Both assertions D-10 asks for are needed:
- the byte-prefix check, which also catches a mapper that rewrites an earlier turn while the messages array still "starts the same";
- the per-dialect directive check (exactly one Anthropic system breakpoint; no directive at all on Chat, including OpenRouter `anthropic/*` routes).

Negative controls show the checks bite. The one known way the encoder breaks append-only, a forced tool on a model that cannot be forced (reshape), is pinned by a test and documented as single-turn only, so Phase 9's loop uses `ToolChoice.Auto`.

Purpose: a cache miss or a thinking-binding break on turn 2+ is silent and expensive. Phase 10's A10 run counts on cache reads from turn 2.
Output: suite and binding additions, one Anthropic-only pin test, one KDoc paragraph.

Contention: wave 7 is this plan only. It starts after 08-06 has merged and never runs two Gradle invocations at once.
</objective>
