<objective>
Prove on the JVM that the library reads and writes the exact bytes SecondBrain and CalTracker already have on users' phones (SC2 JVM leg; D-06, D-11): an independent replica of each app's writer produces pairs under the apps' literal aliases and pref keys that the store reads back unchanged, the store's own pairs open with the replica, and a fixed golden vector pins the byte layout and the NO_WRAP-compatible Base64 (D-05; KEY-03 encoding). The SB source is re-read to confirm the layout (D-11).

Purpose: the whole value of `:keystore` is not changing bytes; these tests catch a format regression before SB or CT plan their migrations.
Output: three test files; no main-source change.

Contention: the phase runs strictly sequentially, one plan per wave (wave 4 is this plan only; it starts after 06-03 has merged), so no two plans ever run `:keystore` Gradle tasks at the same time; this plan never runs two Gradle invocations at once and uses task-scoped `:keystore` commands until its final `:keystore:check`.
</objective>
