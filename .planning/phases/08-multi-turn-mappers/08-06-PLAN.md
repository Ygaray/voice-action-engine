<objective>
Bind the same conformance suite to the Chat Completions mapper on both vendors (XCR-01, D-09), using four derived conversation goldens:
- OpenAI with four parallel calls, a zero-argument call and an error result;
- OpenAI with empty-arguments forms;
- OpenRouter with parallel calls (`tool_calls[].index`);
- OpenRouter on an `anthropic/*` route with `reasoning_details`.

Each is built on the envelope of a real Phase 5 recorded body, with only the synthetic script's tools and arguments (D-07). That proves the D-01 allowlist replay, the D-05 error wrapper, the D-06 repair and the D-11 findings (index kept, reasoning_details kept whole, response-only fields dropped) with the same assertions that pass on Anthropic.

Purpose: SC1 needs one suite on both mappers, and SC3's Chat half needs goldens grounded in real bodies.
Output: one binding, two subclasses, four fixtures, four manifest rows, and the manifest non-vacuity check.

Contention: wave 6 is this plan only. It starts after 08-05 has merged and never runs two Gradle invocations at once.
</objective>
