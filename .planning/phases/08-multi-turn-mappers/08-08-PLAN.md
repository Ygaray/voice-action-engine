<objective>
Build the multi-turn live recorder as code only, proven key-free, by extending (not forking) the two existing opt-in capture tasks (D-08 refreshed). Its plan is bounded and stated in code: 19 requests at most, cheapest models, and the two Sonnet 5.5 thinking legs explicitly capped (D-07 refreshed). It writes raw bodies only under `build/`, sanitizes each conversation with one id map, and re-proves every captured golden through the same replay the conformance suite uses before it counts as met.

The plan then closes the phase gate on the merged tree. 08-09 only decides, runs and commits.

Purpose: SC3's "recorded, sanitized real response bodies" and SC2's real thinking golden need a recorder that cannot overspend, leak, or write a golden that does not replay.
Output: two new test files, two extended live classes, two task edits, the phase-gate evidence.

Contention: wave 8 is this plan only. It starts after 08-07 has merged and never runs two Gradle invocations at once.
</objective>
