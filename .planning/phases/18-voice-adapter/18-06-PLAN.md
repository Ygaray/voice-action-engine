<objective>
Land the two permanent Gradle gates that prove SC-2 for `:stt` (what `:voice-adapter` publishes, and who else can resolve
`:stt`), and the negative controls that prove those gates are not vacuous.

Purpose: `verifyModuleGraph` only sees project edges, and `:stt` is an external binary dependency, so today nothing proves

corrections and coroutines-android onto every consumer (the A1 problem again). D-03 gives Phase 18 this gate. This plan runs
after the mapper tests (plan 03) and the sentinel test (plan 05) so every test already exists when the security gates land.
Output: `verifyAdapterSttCompileOnly`, `verifySttConfined`, `scripts/verify-stt-negative-controls.sh` and its Part 6 hook.
</objective>

## Execution notes

- Phase branch, serial. One Gradle invocation at a time with the single-use-daemon recipe in every command; never
  `./gradlew --stop`; never kill another process; if earlyoom kills a run, stop and report (no retry loop).
- All commands are `--offline`: the `:stt` v0.7.0 AAR and its two compile-scope artifacts were cached by plan 01's online run.
- Failure marker texts are a contract between the gates and the controls script. Keep them exactly:
  `:voice-adapter must keep :stt compileOnly` (every failure of the adapter gate except its own vacuity messages, which say
  `:stt gate is vacuous`), and `resolves the :stt group` (the confinement gate). The existing marker `forbidden project
  dependencies` (from verifyModuleGraph) is reused for the providers plant.
- The `:stt` group literal is `com.github.Ygaray.voice-engine-android`; it must be a full-string match. The applied script
  `gradle/invariants.gradle.kts` cannot reference plugin classes and cannot share a value with a build file, so each file
  holds its own copy of the literal.
- No planning ids in any comment or KDoc; no app-domain words in main sources.
