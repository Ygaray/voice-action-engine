<objective>
Finish the mapper and pin it with tests: the complete `FinalSegment.toCommandInput` overload set, the `:stt`-type-free entry
points, the closed-set language normalizer, the redaction sentinels and the reflection pin of the frozen public surface.

Purpose: ADPT-01's value is that an app replaces its hand-written segment-to-input mapping with one call whose behaviour is
exactly what both consumer apps do today (closed-set labels), without ever leaking the transcript or guessing a language.
The names freeze at the v1.1.0 tag and the API only grows additively after, so the surface is pinned by a test now, before the
publication and security gates of the later plans.
Output: the complete mapper and four test classes (mapping, labels, redaction, API shape).

Flagged unresolved assumption (edge probe: ADPT-01 came back unclassified and unresolved, no SPEC exists): the requirement
text does not state boundary behaviour. This plan resolves it explicitly instead of dropping it: blank, empty, very long and
lone-surrogate text; null, blank, mixed-case, padded, regional (en-US, es-419) and unknown labels; a null context and a null
parent run id; and the must-NOT items in `must_haves.prohibitions` (never guess a language when `:stt` gave none; never
stringify or log the transcript), each backed by a test.

Plan decision made here (planner, `ai-auto`, rated one-way because the names freeze at the tag; recorded for review and
repeated in the surface review of plan 07):
- PD-04: public names are `toCommandInput` (extension on `FinalSegment`, overloads: none; context; context and parentRunId),
  `commandInputOf(transcript, languageLabel)` (overloads: plus context; plus context and parentRunId) and
  `normalizeSttLanguageLabel(raw)`. Explicit overloads, never default parameters (additive-only evolution). JVM facade classes
  `FinalSegmentCommandInput` (stt-typed file) and `SttLanguageLabels` (stt-free file), kept separate so the stt-free class
  never references an :stt class in any signature.
