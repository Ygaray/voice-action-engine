<objective>
Scaffold the optional `:voice-adapter` module end to end: one `FinalSegment` from `:stt` v0.7.0 becomes a `CommandInput` in a
JVM unit test, resolved through a pinned, group-filtered JitPack repository, and the module is registered in the generic
module plumbing so every manifest-driven script and gate sees it.

it) that keeps `:core` free of any other hub (L7). Proving the whole resolve, compile, test and publish path with one real
segment first means a dead end shows up after one commit, not after the full mapper, docs and gates exist.
Output: the `:voice-adapter` module with its first public function, the catalog and settings entries for `:stt`, and the
manifest, `allowedEdges`, ML-scope and `jitpack.yml` rows.

## Execution notes

- Phase branch, serial. Host memory is tight (earlyoom, swap often full): one Gradle invocation at a time, always with the
  single-use-daemon recipe used in every verify command below. Never run `./gradlew --stop`. If earlyoom kills a run, stop
  and report; do not loop.
- Task 1's verify is deliberately ONLINE (no `--offline`): the `:stt` AAR and its two transitive compile artifacts must be
  fetched into the Gradle cache once. Every later command in the phase uses `--offline`.
- No planning ids (threat ids, decision ids, review ids, or a phase number followed by a decision id) in any source comment or
  KDoc: detekt ForbiddenComment and scanBannedConstructs reject them. No app-domain words (the two consumer app names, note,
  card, food) in main sources.
- No npm, pip or cargo package is installed (the one external artifact is the owner's own JitPack mirror, approved in
  18-RESEARCH.md "Package Legitimacy Audit"). No ORM or schema file and no external HTTP API integration are in scope, so the
  schema gate, the assumption-delta gate and the API-coverage matrix do not apply.
