<objective>
Open the keystore's key-custody seam to app unit tests, behind a compile-time opt-in (SEAM-07, D-07): `KeyAccess` becomes
a public plain `interface` (two members, so `fun interface` cannot compile, and collapsing it to one member would break
read-never-creates; the orchestrator accepted this correction), and `ApiKeyStore` gains exactly one public constructor
`(dataStore, slots, keyAccess)`. Both carry `@DelicateKeyAccess`, a `@RequiresOptIn(level = ERROR)` marker. Opt-in can
only be proven from a different module than the one that owns the marker, so the negative-compile proof plants code in
`:sample`. REQUIREMENTS.md SEAM-07 is reworded to what is built.
