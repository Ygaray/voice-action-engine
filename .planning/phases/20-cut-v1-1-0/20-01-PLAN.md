### Phase-wide rules (referenced by number from later plans)

- **R1 branch and pushes.** Work happens on whichever branch the execute workflow checked out. Gates 4 and 5 need
  HEAD == origin/main on main, so before every push: `git checkout main && git merge --ff-only <work branch>`. Every push is
  a plain `git push origin main` (no force) after the OK on `pushing main <sha>` (research A7). If origin moved (the orchestrator
  commits section 11 rows), merge it (`git merge --no-edit origin/main`, never rebase); ledger-only contract changes are
  accepted by gate 7.
- **R2 host recipe (D-07).** Every Gradle run: `GRADLE_OPTS="-Dorg.gradle.daemon=false -Dorg.gradle.workers.max=2
  -Dorg.gradle.parallel=false -Dkotlin.compiler.execution.strategy=in-process -Dorg.gradle.jvmargs=-Xmx1536m"` and
  `./gradlew --offline -q -Dorg.gradle.workers.max=2 -Dorg.gradle.parallel=false ...`; one Gradle process at a time; before it
  `awk '/^MemAvailable:/{exit !($2>=5242880)}' /proc/meminfo` and `! pgrep -f '[v]oice-action-engine/gradle/wrapper/gradle-wrapper.jar'`;
  real exit status, never behind a pipe; an earlyoom-killed step is re-run ONCE then reported; never `./gradlew --stop` and never
  kill another process.
- **R3 gate 7 timing.** After W only `.planning/**` and `<module>/api.txt` change. Nothing in `scripts/`, docs, sample or module
  sources changes after plan 20-07 fixes W.
- **R4 section 11.** `CROSS-REPO-SCOPE-CONTRACT.md` is never edited here; the ledger row is relayed (20-11 T3).
- **R5 relays are signal-waits.** A grant, an answer or an OK is only ever copied from a relayed message, with relayed_by and a
  UTC time; an unattended run waits, it never authors one.
- **R6 evidence hygiene.** No key, transcript, argument value or home-directory path in any evidence file; print counts and
  path:line only.
