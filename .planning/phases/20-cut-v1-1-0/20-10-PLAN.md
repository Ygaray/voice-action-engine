## Execution notes

- **Rule C0 (no commit in this plan).** Do not `git commit`, do not stage, do not push main. Planning files this plan writes stay in the working tree.
  The execute workflow's usual per-task commit is suspended for this plan on purpose: every commit would move HEAD away from origin/main (gate 5) and
  away from the SHA named in "tag ready". The closing summary and state commit is made after Task 3's CUT OK (or after a failure, for the record).
- Host rules R2 of plan 20-01 and memory `vae-release-cut-host-oom` (v1.0.1 needed six attempts; five were earlyoom kills with swap full): check
  `free -h` and MemAvailable first (the operator resets swap if it is full; agents never run sudo), `pgrep -af '[G]radleDaemon'` for foreign daemons (note
  them, never stop them), the low-memory GRADLE_OPTS recipe is inherited by every gate, and `preflight` and `cut` each run the heavy gates (9, 10, 12, 13)
  in full. `timebox_s: 14400` counted from `gates_started:`. An earlyoom kill: stop, report, one re-run, no loop.
- W (full 40-hex) is the `wiring_sha` of 20-QUIET-WINDOW-01.md; HEAD is whatever `git rev-parse HEAD` prints now.
- `release-cut.sh` prints `PREFLIGHT OK tag=<tag> commit=<HEAD> wiring=<W> gates=<list>` and `CUT OK tag=<tag> commit=<HEAD> tag_object=<sha> pushed=refs/tags/<tag>`.
  Capture each run into a log file and the evidence file; the exit status is `$?` of the run itself.
