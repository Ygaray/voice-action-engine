## Type contract (exact shapes this plan creates)

Regular classes unless stated, explicit visibility, KDoc on every public member, constants as top-level `private const val`.

- `ToolSpec` (package `...core.strategy`): public constructor `(name: String, description: String, inputSchema: JsonObject, mutating: Boolean = false, terminal: Boolean = false)` (kotlinx.serialization.json `JsonObject`). `init`: `require(name.isNotBlank())`; `require(!(terminal && mutating))` with message "a terminal tool must be non-mutating". Properties of the same names. `public companion object` with `clarification(name: String): ToolSpec` and `clarification(name: String, description: String): ToolSpec` returning `terminal = true`, `mutating = false` and the clarification schema (below). `toString` = `ToolSpec(name=<name>, mutating=<b>, terminal=<b>)`. KDoc: Phase 3 may add members additively; a terminal tool ends the run with `Completed.terminalCall`.
- Clarification schema, built with `buildJsonObject` in exactly this key order so `inputSchema.toString()` is byte-stable: `{"type":"object","properties":{"question":{"type":"string"},"options":{"type":"array","items":{"type":"object","properties":{"id":{"type":"string"},"label":{"type":"string"}},"required":["id","label"],"additionalProperties":false}}},"required":["question","options"],"additionalProperties":false}`. Default description: `Ask the user to choose one of the listed options instead of guessing.`
- `TerminalCall` (package `...core.strategy`): public constructor `(toolName: String, arguments: JsonObject)`; `public fun asClarification(): Clarification?` parses `question` (a JSON string primitive) and `options` (a JSON array whose every element is an object with string primitives `id` and `label`; extra keys ignored); any other shape returns null; never throws. `toString` = `TerminalCall(toolName=<name>, argumentCount=<n>)` (never argument values).
- `Clarification` (same package): public constructor `(question: String, options: List<ClarificationOption>)`; `toString` = `Clarification(questionLength=<n>, options=<count>)`.
- `ClarificationOption` (same file): public constructor `(id: String, label: String)`; KDoc: `id` is opaque to the engine (an app row id, list id); `toString` = `ClarificationOption(idLength=<n>, labelLength=<n>)`.
- `ActionKind` (package `...core.commit`): `@JvmInline public value class ActionKind internal constructor(public val value: String)`, companion `COMMITTED` committed, `HELD` held, `PREVIEW` preview, `IS_ERROR` is_error; `toString()` = value; KDoc: open set, keep an `else`.
- `FinishedKind` (package `...core.commit`): same form, `READ` read, `PREVIEW` preview, `ERROR` error. KDoc: READ is never reported to the commit sink; PREVIEW is reported as a preview action; ERROR is a mutating call rejected before the gate, reported as is_error with applied false.
- `Usage` (package `...core.telemetry`): public constructor `(inputUncached: Long, cacheRead: Long, cacheWrite: Long, output: Long)`, each required >= 0; `public val total: Long` = the four-way sum (SB's summed semantics); `public operator fun plus(other: Usage): Usage`; companion `ZERO`; equals/hashCode by the four fields; `toString` prints the four and total. KDoc spells out normalization: Anthropic `input_tokens` already excludes cached tokens (inputUncached = input_tokens, cacheRead = cache_read_input_tokens, cacheWrite = cache_creation_input_tokens); OpenAI `prompt_tokens` includes them (inputUncached = prompt_tokens - cached_tokens, cacheRead = cached_tokens).
- `TraceCode` (package `...core.telemetry`): `@JvmInline public value class TraceCode internal constructor(public val value: String)`, companion constants listed in "Artifacts" with values in lower snake case (gate_error, apply_error, apply_cancelled, sink_error, listener_error, policy_source_error, strategy_error, engine_timeout, escalation_suppressed, tier_skipped_policy, max_tier_unknown, offline_unavailable, on_device_unavailable, commit_held_cancelled); `toString()` = value.
- `Guarded.kt` (package `...core.internal`, all internal): `internal class EngineFault(val errorClass: String, val timeoutLeak: Boolean)`; `internal suspend inline fun <T> guarded(onFault: (EngineFault) -> T, block: () -> T): T` with this catch order: `TimeoutCancellationException` (rethrow if `!currentCoroutineContext().isActive`, else `onFault(EngineFault(<simple class name>, timeoutLeak = true))`), then `CancellationException` (rethrow), then `LinkageError` (fault), then `Exception` (fault). `errorClass` = the exception's simple class name, falling back to the last segment of its JVM name when the simple name is empty. Exactly one `@Suppress("TooGenericExceptionCaught")` on this function, with a one-line comment saying it is the engine's single never-throw collapse point. Other `Error`s (OutOfMemoryError, AssertionError) are not caught.
