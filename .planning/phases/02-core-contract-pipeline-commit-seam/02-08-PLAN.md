## Type contract

Package `...core.telemetry` unless stated; regular classes, explicit visibility, KDoc, safe `toString`.
- `TurnRecord`: public constructor `(provider: ProviderId?, model: String?, stopReason: String?, toolNames: List<String>, usage: Usage, latencyMillis: Long)`; public getters; toString prints all fields (ids, codes, tool names, usage, latency). KDoc: one model round trip; never carries text, arguments or results.
- `CommandTrace`: add `usage: Usage` (sum over attempts). `TierAttempt`: add `turns: List<TurnRecord>`, `provider: ProviderId?` and `model: String?` (from the tier's last turn), `usage: Usage` (sum of its turns). Constructors stay internal.
- `PipelineEvent`: `public interface PipelineEvent { public val runId: String }`, NOT sealed; KDoc: open set, keep an `else`. Nested leaves, internal constructors, public getters, safe toString: `CommandStarted(runId, parentRunId: String?)`, `TierStarted(runId, strategy: StrategyId)`, `TierSkipped(runId, strategy: StrategyId, code: TraceCode)`, `ProviderCall(runId, strategy: StrategyId, turn: TurnRecord)`, `ActionRecorded(runId, position: Int, kind: ActionKind, toolName: String, applied: Boolean)` (covers commit, hold, preview, is_error), `EngineCode(runId, code: TraceCode)`, `CacheNotEngaged(runId, strategy: StrategyId, provider: ProviderId, model: String?)`, `TierFinished(runId, attempt: TierAttempt)`, `RunClosed(runId, terminationCode: String, executedCount: Int, committedCount: Int)`.
- `PipelineEventListener`: `public fun interface PipelineEventListener { public fun onEvent(event: PipelineEvent) }` (non-suspending, D-20).
- `CommandSession` (package `...core.strategy`): add `public abstract suspend fun recordTurn(turn: TurnRecord)` and `public abstract val tokensUsed: Long` (run-cumulative `Usage.total` of recorded turns). KDoc: strategies that loop enforce `policy.maxIterations`, `policy.tokenCeiling` and `policy.maxTokensPerTurn` with these.
- `PipelineBuilder` (package `...core.pipeline`): add `public var listener: PipelineEventListener? = null`.
- Internal: RunRecorder emitting methods become suspend and dispatch through `guarded` (fault: record `TraceCode.LISTENER_ERROR` in codes and emit nothing for it); new internal `actionRecorded(action)`, `runClosed(termination)`, `turnRecorded(strategy, turn)`, `commandStarted()`, and `cacheNotEngaged(strategy, provider, model)` (Phase 3's in-`:core` cache detection calls it; no public emission API).
- Fixtures (testFixtures, public): `FakeClock` (manual `now` with `advanceBy(millis)`, usable as the DSL `clock`), `RecordingEventListener` (thread-safe ordered `events`, optional throwing mode).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine -> app listener / logs | events and traces are designed to be logged |
| strategy / provider -> engine | turn records come from engine strategies and future transports |
| app listener -> engine | listener code runs on the pipeline coroutine and may throw |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-35 | Information disclosure | transcript, arguments, results, snapshots or keys in trace/events/toString | high | mitigate | Events carry ids/codes/counts/tool names only (ActionRecorded never holds the action object); RedactionCanaryTest sweeps every output type |
| T-02-36 | Denial of service | a throwing listener aborting the command | medium | mitigate | guarded dispatch; listener_error recorded without re-entering the listener; identical-outcome test |
| T-02-37 | Repudiation | trace disagreeing with what happened (audit gap) | medium | mitigate | Events-equal-trace test; single append point in ActionLedger emits ActionRecorded |
| T-02-38 | Tampering | misreported token usage defeating the token ceiling | medium | mitigate | tokensUsed computed by the engine from recorded turns with SB's summed semantics; worked Anthropic/OpenAI parity example |
</threat_model>
