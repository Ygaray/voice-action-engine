== Cause codes (pending orchestrator confirmation) ==
These are the values KeyState.Unreadable.cause (and CredentialLookup.Unreadable) can carry. Recorded for confirmation before the v1.0.0 tag; not blocking.
- key_missing: the device key that protected the stored value is gone (backup restore, wiped key store). Reported as KeyState.KeyMissing; never recreated silently.
- keystore_unavailable: the key lookup threw (a security exception or a runtime exception); the stored value may be fine. No key is created in that case.
- decrypt_failed: the cipher rejected the pair (bit-flipped ciphertext, wrong key).
- stored_value_malformed: strict Base64 failed in either half, the IV is not 12 bytes, the ciphertext is under 16 bytes, or the decrypted value is blank.
- storage_unreadable: the DataStore could not be read (an I/O error including corruption, or a runtime exception).
