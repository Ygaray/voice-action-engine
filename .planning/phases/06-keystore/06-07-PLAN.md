1. `scripts/run-keystore-instrumented.sh` (bash, `set -uo pipefail`, mode 100755). Header comment: purpose, TESTER only, never substitutes, exit codes, the final-line format, and that it must not run while another agent is driving the TESTER. Constants as listed in the Artifacts section; `ADB="${ADB:-adb}"` names the binary only. A helper prints the final `KEYSTORE_INSTRUMENTED:` line and exits with the given code. Steps in order:
   a. Any argument: ERROR exit 2, reason `usage` (nothing can redirect the target).
   b. `ANDROID_SERIAL` set to anything other than the two TESTER serials: print `TESTER IDENTITY MISMATCH - refusing`, INFRA exit 4, reason `refused_serial`, before any adb call.
   c. Take a non-blocking `flock` on the lock file; busy gives INFRA exit 3, reason `tester_busy`.
   d. Resolve: `$ADB -s $TESTER_USB get-state` equal to `device` selects USB; otherwise `$ADB connect $TESTER_WIFI` then `$ADB -s $TESTER_WIFI get-state` equal to `device` selects wireless; otherwise print `TESTER OFFLINE - not substituting` and give INFRA exit 3, reason `tester_offline`.
   e. Identity on the selected target: a target containing `$PERSONAL_IP` is refused; `getprop ro.serialno` must equal `R5CT10XNKQN`, `ro.product.model` must equal `SM-S908U`, `ro.build.version.sdk` must be at least 35; any mismatch prints `TESTER IDENTITY MISMATCH - refusing` and gives INFRA exit 4, reason `identity_mismatch`.
   f. Print (informational) the target, model, SDK and the foreground activity line from `dumpsys activity activities`.
   g. Build with `./gradlew :keystore:assembleDebugAndroidTest --offline -q` (failure: ERROR exit 2, reason `build_failed`); require exactly one APK under `keystore/build/outputs/apk/androidTest/debug/` (else ERROR, reason `apk_missing`).
   h. Register a trap that uninstalls `$TEST_PKG` from the target; `install -r -t` the APK (failure: if `get-state` no longer answers `device`, INFRA exit 3 reason `tester_offline`, else ERROR reason `install_failed`); confirm `pm list instrumentation` lists `$TEST_PKG/$RUNNER` (else ERROR reason `instrumentation_missing`).
   i. `shell am instrument -w -e class $TEST_CLASS $TEST_PKG/$RUNNER`, output saved to `keystore/build/device-run/instrument.log` and echoed.
   j. Parse: a line `OK (N tests)` with N at least `EXPECTED_MIN_TESTS` gives PASS exit 0 (`tests=N target=... model=... sdk=...`); a line `OK` with fewer tests, `FAILURES!!!`, `Process crashed` or no OK line gives FAIL exit 1 (`tests_run=... failures=...`), printing the failing test names only.
   k. After uninstall, confirm `pm list packages` no longer lists `$TEST_PKG` and print `test package removed`.
2. `scripts/verify-keystore-device-guard.sh` (bash, `set -uo pipefail`, mode 100755): for each scenario, make a temp dir with a fake `adb` script that appends its arguments to `calls.log` and answers per scenario, run the runner with `ADB=<fake>`, and check exit code, message and final line:
   - offline (every call exits 1): exit 3, `TESTER OFFLINE - not substituting`, `reason=tester_offline`;
   - USB impostor (`get-state` answers device, `ro.serialno` answers `R5CTIMPOSTOR`): exit 4, `TESTER IDENTITY MISMATCH - refusing`, `reason=identity_mismatch`;
   - wireless impostor (USB `get-state` fails, `connect` succeeds, wireless `get-state` answers device, `ro.serialno` answers `R5CTIMPOSTOR`): exit 4, `reason=identity_mismatch`;
   - foreign ANDROID_SERIAL (`100.126.94.47:5555`): exit 4, `reason=refused_serial`, `calls.log` empty;
   - extra argument (`--serial 100.126.94.47:5555`): exit 2, `reason=usage`, `calls.log` empty;
   - lock busy (the guard holds the lock file with its own `flock -n` on a spare descriptor, runs the runner, then releases): exit 3, `reason=tester_busy`.
   In every scenario `calls.log` holds no `install`, `instrument` or `uninstall`; every logged call is either `connect 100.118.21.106:1496`, `devices`, or starts with `-s R5CT10XNKQN ` or `-s 100.118.21.106:1496 ` (so a call without -s, or with any other serial, fails the guard). Print `DEVICE GUARD OK` when all pass, else `DEVICE GUARD FAIL: <scenario>` and exit 1. No scenario reaches the Gradle build.
3. `chmod +x` both and commit by explicit path only (mode 100755 recorded).
