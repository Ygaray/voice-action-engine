<objective>
Turn the one-slot tracer into the full per-provider store: delete, the validated slot table (D-01) with loud unmapped writes (D-03), and the write semantics that keep every app's existing data safe: trim and reject blank (D-05 save side), a fresh provider IV on every save, one atomic DataStore update per pair, serialized writes, and a failed write that changes nothing (KEY-01, KEY-02).

Purpose: a copy-pasted alias or pref key would let one provider's save clobber another's key, and a half-written pair would strand it; both become impossible at construction time and by test.
Output: delete and validation in `ApiKeyStore.kt`, row validation in `KeySlot.kt`, four test classes and one recording test double.

Contention: the phase runs strictly sequentially, one plan per wave (wave 2 is this plan only; it starts after 06-01 has merged), so no two plans ever run `:keystore` Gradle tasks at the same time; this plan never runs two Gradle invocations at once and uses task-scoped `:keystore` commands until its final `:keystore:check`.
</objective>

<assumption_delta_decision>
Primary noun: the app-supplied `KeySlot` table (D-01, D-11), one row per provider.
Decision: no-change. A second provider (or a second app) is another `KeySlot` row of data, never a subclass, a per-app store type or a name derived by formula.
Rationale: everything that differs between SecondBrain's one slot and CalTracker's three is a string the app already owns, so the table stays data and the public surface stays one class.
</assumption_delta_decision>
