## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app-private storage / assets -> loader | fixture bytes come from outside the APK build and may be wrong |
| loader -> logs/UI | fixture state is displayed and logged |
| model -> canned executor | tool names and arguments are model-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-05 | Tampering | a stale or edited fixture silently used for the A10 proof | high | mitigate | full SHA-256 compare, no fall-through on mismatch, ShaMismatch state (Tasks 1-2) |
| T-10-06 | Information disclosure | private SB prompt text reaching git, logs or toString | high | mitigate | fixture never committed (hygiene c), state toString carries no content, canary test (Task 2) |
| T-10-07 | Tampering | fixture read at Gradle configuration time breaking JitPack | high | mitigate | runtime-only sources; build scripts never name the fixture (Task 2 grep) |
| T-10-08 | Information disclosure | model-supplied arguments echoed into canned results or logs | medium | mitigate | fixed canned constants; canary test (Task 3) |
| T-10-09 | Tampering | strict schemas wiping optional fields | medium | mitigate | strict null on every synthetic spec (Task 3) |
</threat_model>
