<objective>
Build the first new Gate-1 leg end to end: `grammar_offline` proves the free grammar tier answers an EN and an ES command
and hands a near-miss on to an Unhandled outcome capped by policy, with zero provider calls proven by three explicit
counts. Introduce the `VAE_TRACE` evidence line, in lockstep across the five places that share the closed vocabulary.

Purpose: VER-06 / ROADMAP SC1 "a grammar command under offline-only with zero provider calls", with the proof D-05
asks for (offlineOnly + explicit zero-attempt counts + a tripwire provider, no airplane mode). VAE_TRACE (D-08) is also
the line the plan and router legs (plan 05) report through.
Output: TripwireProvider, GrammarLeg (pack, ladder, verdict), LegId/LegCatalog/LegRunner/AppGraph wiring, VAE_TRACE in
EvidenceLine + filter + golden + guard + LEGS, GrammarLegTest.

Planner decisions recorded here (for the master's veto):
- The grammar leg's engine registers the real providers (behind the request tap, so any HTTP attempt is counted) plus
  the TripwireProvider, and the single-shot tier's selection and capabilities name the tripwire only: offlineOnly drops
  the tier, the engine's router would refuse a non-on-device provider, and the tripwire is the third line; a leak can
  never spend money.
- The guard's capture counts are derived from the golden file's line count instead of a literal, so a later line type
  never needs another edit there (the golden file itself stays lockstep with EvidenceLine through EvidenceLineTest).
- New legs live in their own files (`GrammarLeg.kt` here), with LegRunner dispatching, so LegRunner does not grow past
  readability.
</objective>
