## Type contract

- `ModelCapabilities`: `public class ModelCapabilities internal constructor(public val supportsTools: Boolean, public val caching: CachingMode, public val minCacheablePrefixTokens: Int?, public val charsPerToken: Double)`. `init` validates (minCacheablePrefixTokens null or > 0; charsPerToken finite and > 0). Equality and hashCode by all four fields; `toString` prints all four. Nested `public class Builder internal constructor()` with public `var`s of the same names and defaults true / `CachingMode.NONE` / null / `DEFAULT_CHARS_PER_TOKEN` and an internal `build()`. Companion: `UNKNOWN` (all defaults) and `operator fun invoke(block: Builder.() -> Unit): ModelCapabilities`. KDoc on each property: supportsTools false means a request with tools is refused before any call; minCacheablePrefixTokens null means unknown and keeps the cache diagnostic silent; charsPerToken is an estimate divisor (larger errs silent), never a limit. Later knobs (forced tool choice, reasoning-effort rules) are new Builder properties.
- `CachingMode`: `@JvmInline public value class CachingMode internal constructor(public val value: String)` with companion `EXPLICIT_BREAKPOINTS` explicit_breakpoints, `AUTOMATIC` automatic, `NONE` none; `toString()` = value; KDoc: open set, keep an `else`.
- `ModelCapabilityTable`: `public class ModelCapabilityTable internal constructor(...)` per Artifacts; `lookup` requires a non-blank model; `toString` = `ModelCapabilityTable(overrides=<n>)`. KDoc: public so model pickers can mark or filter tool-incapable models; precedence app override over provider default over unknown-id default; keys are exact ids, never prefixes or families.
