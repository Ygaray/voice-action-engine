## Type contract

- `AiProvider`: `public interface AiProvider` with abstract `public val id: ProviderId` and `public suspend fun complete(call: ProviderCall): ModelResult`; default `public fun capabilities(model: String): ModelCapabilities = ModelCapabilities.UNKNOWN`; default `public val requiresCredential: Boolean get() = true`. KDoc: map the wire format to the neutral types; return `ModelResult.Failure` for every expected failure (status, error type, request id only, never bodies); never log; keep no state between calls; the engine still guards every call. Any later member is a default member.
- `ProviderCall(model: String, request: ModelRequest, credential: Credential?, capabilities: ModelCapabilities)`: public constructor, no default arguments; `require(model.isNotBlank())`. `toString` = `ProviderCall(model=<m>, messages=<n>, tools=<n>, credential=<provider or none>)`.
- `ModelResult`: `public abstract class ModelResult internal constructor()` with nested `public class Success(public val response: ModelResponse)` and `public class Failure(public val reason: FailureReason, public val details: FailureDetails?)` plus secondary `Failure(reason)`. `toString` = `ModelResult.Success(response=<response>)` / `ModelResult.Failure(reason=<r>, details=<d>)`. KDoc: open set, keep an `else`; returned, never thrown.
- `ToolSpec`: `public class ToolSpec @JvmOverloads constructor(name, description, inputSchema, mutating: Boolean = false, terminal: Boolean = false, strict: Boolean? = null)`; existing `init` checks unchanged; `toString` = `ToolSpec(name=<n>, mutating=<b>, terminal=<b>, strict=<b or null>)`; companion `clarification(...)` unchanged.
