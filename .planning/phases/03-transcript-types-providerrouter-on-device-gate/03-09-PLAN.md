<objective>
Implement TEL-03: after each successful routed response, decide in `:core` whether the prompt cache should have engaged and did not, and if so emit the existing `CacheNotEngaged` event through `RunRecorder.cacheNotEngaged` (Runtime Decision cache-detect), following D-08 (when to fire), D-09 (the conservative estimate, divisor 4.0 capped by billed prompt tokens) and D-10 (per caching mode).

Purpose: a cache that silently stops hitting costs money and latency on every agentic turn; the diagnostic must be loud when the engine is sure and silent whenever it is not.

Output: 1 new internal main file, 2 modified main files, 1 test class.
</objective>

## Rule (exactly D-08..D-10)

`fires = staticPrefix && minimum != null && estimate >= minimum && when (caching) { EXPLICIT_BREAKPOINTS -> cacheRead == 0 && cacheWrite == 0; AUTOMATIC -> successfulTurn >= 2 && cacheRead == 0; else -> false }` with `estimate = min(floor(prefixChars / charsPerToken), saturating(inputUncached + cacheRead + cacheWrite))`. Turn counting: the routed handle increments an atomic counter for each successful response before evaluating, so the first success is turn 1.
