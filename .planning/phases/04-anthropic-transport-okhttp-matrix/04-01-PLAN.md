## Type contract

- `ModelCapabilities` gains `public val supportsForcedToolChoice: Boolean` as the fifth constructor parameter (internal constructor, so no consumer binds to it). KDoc: false means the model rejects a request that forces a named tool, so a request that requires one is sent with automatic tool choice plus an instruction to call that tool; true (the default) sends the forced choice. Neutral wording only (no vendor or model names).
- `AnthropicModels`: exact-id lookup (a `when` on the id string or a private map), building each entry with `ModelCapabilities { ... }`. Unknown ids return `ModelCapabilities { caching = CachingMode.EXPLICIT_BREAKPOINTS }` (forced true, minimum null) because `UNKNOWN` has caching NONE and Anthropic always supports explicit breakpoints (research A9). KDoc names the source (Anthropic errors and prompt-caching docs, verified 2026-09-30) and says the app patches any field through `PipelineBuilder.capabilities`.
