<objective>
Wire one Anthropic command end to end (tracer), then make the request encoding cache-correct and byte-stable (PROV-04/05/06, D-11) and the response decoding complete (usage, stop reasons, tool calls, native replay, malformed answers).

Purpose: this is the slice a consumer actually uses: `AnthropicProvider { }` registered in `commandPipeline` turns a neutral `ModelRequest` into a correct Messages API call with exactly one cache breakpoint on the frozen tools + system prefix.
Output: the public `AnthropicProvider`, internal transport, encoder and decoder; four test classes (one is the shared JSON fixture file).
</objective>

## Type contract

- `AnthropicProvider internal constructor(internal val transport: AnthropicTransport, private val callTimeoutMillis: Long, private val readTimeoutMillis: Long) : AiProvider`; `id = ProviderId.ANTHROPIC`; `requiresCredential` stays the default true; `capabilities(model) = AnthropicModels.capabilities(model)`; `complete(call) = transport.send(call)`; `toString()` = `AnthropicProvider(callTimeoutMillis=<n>, readTimeoutMillis=<n>)`. KDoc on the class: what it does, that it never logs, keeps no per-call state, that the app's OkHttpClient is used through a derived copy without its interceptors, listeners, authenticator, cookies or redirects, and a prose usage example (`commandPipeline { provider(AnthropicProvider { httpClient = shared }) }`).
- `Builder internal constructor()`: public vars per must_haves truth 2 with KDoc; internal vars `baseUrl: HttpUrl` (default the production constant) and `ioDispatcher: CoroutineDispatcher` (default `Dispatchers.IO`); `internal fun build()` validates, derives the client with `cleanClient(httpClient, callTimeoutMillis, readTimeoutMillis)` and creates the transport. Later plans add Builder members only.
- Constants (private, top-level in the file that uses them): production base URL `https://api.anthropic.com/`, version `2023-06-01`, path `v1/messages`, header names, default timeout 60 000.
